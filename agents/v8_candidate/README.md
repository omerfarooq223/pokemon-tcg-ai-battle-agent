# V8 V5-Recovery Candidate

V8 is a score-informed recovery build rather than an unproven deck replacement.

- Deck: frozen V5 configuration with two Xerosic's Machinations and one Cook.
- Policy: frozen V5 gameplay with an exact-deck, deployment-safe loader.
- Goal: reactivate the balance that produced V5's 965 peak without importing later policy changes that failed to beat it reliably.
- Runtime behavior remains general and state-driven. It contains no opponent names, replay IDs, or opponent-specific branches.

The Mega Starmie ex/Cinderace structural prototype was rejected after losing 6-34 to V5 and 2-38 to V7 in its initial swapped-seat screens. A V5-deck/V7-policy blend was also rejected after losing 975-1022-3 to V5 in a fresh 2000-game run. Both are preserved under `experiments/`.
