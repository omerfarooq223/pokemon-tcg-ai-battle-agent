# Rejected V8 Mega Starmie ex / Cinderace Prototype

This prototype used a replay-derived Mega Starmie ex/Cinderace tempo deck and a dedicated Stage 1, Energy, healing, spread-target, and attack-effect planner.

Initial swapped-seat results:

- 25-15 versus random.
- 6-34 versus frozen V5.
- 2-38 versus V7.

Older V5 and V7 policies also lost badly when piloting the same deck, so the first-screen failure was not only a bug in the new policy. The architecture remains useful research evidence, but it is not safe to package or upload as V8.
