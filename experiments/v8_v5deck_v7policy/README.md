# V8 V5-Deck / V7-Policy Screen

This experiment isolates the leaderboard-visible V5-to-V6 deck change.

- Policy: frozen V7 gameplay policy and deployment-safe embedded deck loading.
- Deck: frozen V5 deck with two Xerosic's Machinations and one Cook.
- Purpose: determine whether restoring V5's healing slot while retaining V7 policy is a credible conservative V8 baseline.
- Status: rejected. It scored 980-1013-7 versus frozen V5 over 2000 swapped-seat games, 1007-992-1 versus V7 over 2000, and 462-536-2 versus V6 over 1000. A fresh run scored 975-1022-3 versus V5. Final V8 instead preserves V5 gameplay exactly and adds only loader hardening.
